# Welcome 👋

Hi, and welcome to **acme**, a small demo repo standing in for the Acme
platform. It is intentionally tiny, so it's a fair thing to poke at while you
are trying out Superset.

## What the repo is

A quick tour of the two source files and the tooling:

- `src/input.ts` — helpers that normalise what someone types into the command bar
- `src/icons.ts` — the shared icon size scale
- `src/input.test.ts` — unit tests for the helpers above

## Getting started

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm test        # run the unit tests
```

A link over to [README.md](./README.md) covers the rest.
